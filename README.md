# Text Analytics Pipeline

A robust, multi-stage Python pipeline for automated text analytics, language filtering, fine-grained sentiment analysis, and semantic topic tagging on customer review datasets.

---

## 🌟 Key Features

* **Language Filtering (`app/language_filter.py`)**: Uses `langdetect` to filter non-English or empty reviews gracefully, marking unsupported inputs as `language unsupported`.
* **Text Preprocessing (`app/preprocess.py`)**: Cleans and normalizes raw customer review text.
* **Sentiment Analysis (`app/sentiment.py`)**:
  * Utilizes `cardiffnlp/twitter-roberta-base-sentiment-latest` transformer model for high-accuracy sentiment predictions (`Positive`, `Negative`, `Neutral`).
  * **Contrast Word Logic (`predict_sentiment_v2`)**: Detects contrast keywords (`but`, `however`, `though`, `yet`), splits multi-clause reviews, and resolves mixed sentiment.
  * **Confidence Thresholding**: Overrides single-clause predictions with confidence below `LOW_CONFIDENCE_THRESHOLD = 55` to `"Neutral"`.
* **Semantic Topic Tagging (`app/topics.py` & `app/topics_config.py`)**:
  * Uses `SentenceTransformer` (`all-MiniLM-L6-v2`) to compute cosine similarity against configured topic descriptions (`Camera`, `Battery`, `Delivery & Shipping`, `Customer Support`, `Price`, etc.).
  * Automatically assigns `"Uncategorised"` if no topic clears the similarity threshold.
* **Pipeline Integration (`app/pipeline.py`)**: Integrates language checking, preprocessing, sentiment prediction, and topic tagging into a unified `analyze_review()` function.
* **Batch Processing (`app/test_pipeline_on_file.py`)**: Reads review datasets, processes them in batch, outputs summary metrics, and exports results to `data/analyzed_reviews_output.csv`.
* **Model Accuracy Evaluation (`app/evaluate_accuracy.py`)**: Evaluates sentiment prediction performance against `data/labeled_validation_set.csv`, calculating accuracy percentage, classification reports (precision, recall, f1-score), confusion matrices, and detailed mismatch tables using `sklearn.metrics`.

## 🚀 Getting Started

### 1. Installation

Ensure Python 3.9+ is installed and set up your virtual environment:

```powershell
# Create & activate virtual environment
python -m venv venv
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

---

### 2. Running Batch Analysis on a File

Process `data/sample_customer_reviews.csv` and generate `data/analyzed_reviews_output.csv`:

```powershell
python -m app.test_pipeline_on_file
# or
python app/test_pipeline_on_file.py
```

---

### 3. Evaluating Model Accuracy

Run accuracy evaluation against `data/labeled_validation_set.csv`:

```powershell
python -m app.evaluate_accuracy
# or
python app/evaluate_accuracy.py
```

---

### 4. Running Individual Pipeline Components

Test individual modules with embedded sample test suites:

```powershell
# Test sentiment module
python -m app.sentiment

# Test topic tagging module
python -m app.topics

# Test full single-review pipeline
python -m app.pipeline
```
